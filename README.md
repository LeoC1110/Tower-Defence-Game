# Tower Defence Game

A Unity tower defence prototype focused on enemy wave spawning, tower placement, basic combat logic, and player resource management.

## Features

- Enemy wave spawning system
- Tower placement mechanics
- Basic enemy movement and health system
- Player resource / score tracking
- Win and lose conditions

## Tech Stack

- Unity
- C#
- Git / GitHub

## What I Learned

- Implementing gameplay loops in Unity
- Managing enemy spawning and object behavior
- Structuring C# scripts for gameplay systems
- Debugging game logic and scene interactions
